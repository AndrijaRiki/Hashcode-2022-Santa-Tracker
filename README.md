# Overview

This repository contains my implementation for the **Google Hash Code 2022 Final Round** challenge.

The task is to optimize Santa's movement on a 2D map while:

- delivering gifts
- respecting acceleration constraints
- managing carrot consumption
- maximizing total score
- operating within a strict time limit

The complete official problem statement is included in this repository:

📄 `hashcode_2022_final_round.pdf`

---

# Problem Statement

Santa moves on a frictionless 2D plane.

At each step Santa can:

- accelerate in one of four directions
- float with current velocity
- load carrots
- load gifts
- deliver gifts

The objective is to maximize the total delivered gift score.

For full details, constraints, and official examples, see:

```txt
hashcode_2022_final_round.pdf
```

---

# Solution Approach

This project uses **Simulated Annealing** as the primary optimization technique.

The algorithm attempts to:

- generate candidate movement sequences
- evaluate total score
- explore neighboring solutions
- probabilistically accept worse solutions
- gradually converge toward better trajectories

Main implementation:

```txt
Main.cpp
```

# Algorithm Details

The optimization is based on **Simulated Annealing**.

---

## State Representation

Each state represents:

- Santa's position
- velocity
- loaded gifts
- loaded carrots
- elapsed time

---

## Neighbor Generation

Neighbors are generated by:

- modifying accelerations
- changing float durations
- reordering deliveries
- altering loading strategies

---

## Objective Function

The scoring function tries to maximize:

```txt
Total delivered gift score
```

while respecting:

- time constraints
- acceleration limits
- weight restrictions

---

## Acceptance Probability

Candidate solutions are accepted based on:

```txt
exp(-(ΔE)/T)
```

where:

- ΔE = score difference
- T = current temperature

---

## Cooling Schedule

Temperature gradually decreases during optimization.

This allows:

- exploration early on
- exploitation near the end
